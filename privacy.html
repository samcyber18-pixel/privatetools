PrivateTools privacy

PrivateTools is designed around local-first file processing for the current four tools.

What happens to my files?

For image compression, image conversion/resizing, PDF merging and PDF splitting, the core file operations are performed in the browser. The current PDF tools load the pdf-lib JavaScript library from jsDelivr; loading the library is separate from uploading the selected PDF data to an application backend.

Do I need an account?

No account is required to use the current four tools.

Can the service change?

Yes. As the product grows, additional features may introduce optional servers or third-party services. Any future change should be reflected in this policy and in the relevant tool's description.
