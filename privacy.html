PrivateTools privacy

PrivateTools is designed around local-first file processing for the current four tools.

What happens to my files?

For image compression, image conversion/resizing, PDF merging and PDF splitting, the core file operations are performed in the browser. The current PDF tools load the pdf-lib JavaScript library from jsDelivr; loading that library is separate from sending the selected PDF contents to an application backend.

Do I need an account?

No account is required to use the current four tools.

What about community features?

During the zero-budget phase, community discussions and polls are hosted on GitHub Discussions. Those interactions are subject to GitHub's own policies and account requirements.

Can the service change?

Yes. As the product grows, additional features may introduce optional servers or third-party services. Any future material change should be reflected in this policy and the relevant tool description.
