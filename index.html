PRIVACY

Built around local-first processing.

For the four file operations in this version, PrivateTools does not require a backend that receives the selected file. Image processing uses browser image/canvas APIs. PDF processing uses the PDF library loaded by the page. This describes how the tool is designed to process files; it is not a legal certification or guarantee.
